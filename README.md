# MAJO_Eng
La app de estudio de inglés de Majo
# ⭐ Star English

Mini-app de práctica de inglés para repasar **Starter + Unidades 1, 2 y 3** del libro Oxford *Bright* (3er grado).

Hecha para Majo: ejercicios cortos con dibujos, en inglés, sin pistas que adelanten la respuesta.

## Qué tiene
- **Today's session**: 10 preguntas mezcladas (con más peso en lo que más cuesta: *there is/are*, *this/these*, *spelling*) y repaso de los errores al final.
- **Misiones sueltas**: there is/are · I like/can/I've got · this/these · spelling · yes-no · hacer preguntas · and/but/or.
- **Progress**: historial de cada práctica (fecha, puntaje y en qué se equivocó) + racha de días.

El progreso y el historial se guardan **en el dispositivo** (no se sube nada a internet).

## Cómo se usa
Es un solo archivo `index.html`. Se abre en cualquier navegador. En la tablet conviene **"Agregar a pantalla de inicio"** para que quede como una app.

## Publicado con GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.

## Para actualizar
Reemplazar `index.html` en el repo y hacer commit. La URL se actualiza sola en ~1 min; el progreso del dispositivo se mantiene.
